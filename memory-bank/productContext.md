# Product Context

Describe the product.

## Overview

iCoachie is a digital platform designed for Kochi's academies, students, and parents to facilitate seamless management of sports training and education. It enables scheduling of courses, student registration by coaches, attendance tracking, performance evaluations, and allows sports clubs to manage registrations for all stakeholders.

## Core Features

- Course Scheduling: Plan and manage training sessions and courses.
- Student Registration: Coaches can register students and manage their profiles.
- Attendance Tracking: Record and monitor student attendance for sessions.
- Evaluations: Conduct and store performance evaluations for students.
- Sports Club Management: Allow clubs to register and manage academies, coaches, students, and parents.
- Authentication & Authorization: User registration, login, roles (Student, Parent, Coach, Academy Admin, Club Admin).
- Profiles: Manage profiles for students, coaches, and parents with relevant metadata.

## Technical Stack

- Backend: Node.js, TypeScript, Express, PostgreSQL (psql)
- Frontend: Next.js (TypeScript)
- Auth: bcrypt, JWT
- Email: nodemailer


## Project Description

iCoachie is a Next.js 14+ web application with TypeScript and React 19, designed as a sports coaching platform. It features a glassmorphism UI with Tailwind CSS, supporting multiple user roles: Club Admins, Coaches, Freelancers, and Parents/Kids. The platform enables discovery of clubs and coaches, registration of children, session booking, attendance tracking, progress monitoring, online payments, messaging, and performance evaluations.
